# BandPlan Admin Console

Отдельная админ-панель для чтения и редактирования данных Supabase проекта BandPlan. Не изменяет репозиторий приложения BandPlan.

## Возможности

- Обзор таблиц схемы `public` и число записей.
- Просмотр, поиск, создание и изменение строк в таблицах с первичным ключом.
- Пользователи Supabase Auth доступны через отдельное серверное действие (только чтение).
- Корзина с сохранением снимка строки перед удалением и возможностью восстановления.
- Проверка сессии Supabase и email allowlist на сервере.

## Подключение

1. В настройках Supabase проекта возьмите Project URL и публичный anon/publishable key.
2. Скопируйте `config.example.js` в `config.js` и заполните значения. Никогда не вставляйте `service_role` key в `config.js`.
3. В Supabase SQL Editor выполните миграцию `supabase/migrations/20261029_bandplan_admin_recycle_bin.sql`.
4. Разверните функцию:
   ```sh
   supabase functions deploy bandplan-admin
   ```
5. Установите secrets для Edge Function:
   ```sh
   supabase secrets set ADMIN_EMAILS="your-email@example.com" ADMIN_CORS_ORIGIN="https://YOUR-USER.github.io"
   ```
   Проверьте, что окружение функции содержит `SUPABASE_URL`, `SUPABASE_ANON_KEY` и `SUPABASE_SERVICE_ROLE_KEY`.
6. Разместите репозиторий на статическом хостинге. Для GitHub Pages включите Pages для ветки `main`, корневая папка `/`.

## Важные ограничения безопасности

- В браузере используются только публичный anon key и пользовательская сессия.
- Проверка `ADMIN_EMAILS` производится Edge Function после проверки JWT через Supabase Auth.
- Не включайте прямой доступ браузера к таблицам с привилегиями service role.
- Удаление сохраняет JSON-снимок строки, затем удаляет её. Внешние ключи могут запрещать удаление — тогда операция завершается ошибкой.
- Восстановление может завершиться ошибкой, если первичный ключ уже занят или отсутствуют связанные данные.
- У таблиц без первичного ключа изменение/удаление через UI недоступно.
- Перед использованием на рабочей базе сделайте резервную копию.
- Это универсальная начальная версия; большие бинарные поля и специальные таблицы могут требовать адаптации.


## Установка на телефон (PWA)

Панель поддерживает установку как приложение на Android, iPhone/iPad и компьютерах через HTTPS GitHub Pages. Это PWA: устанавливается с сайта и открывается в отдельном окне, но не публикуется автоматически в Google Play или App Store.

- **Android (Chrome):** откройте страницу, нажмите «Установить» или выберите «Установить приложение» в меню браузера.
- **iPhone/iPad (Safari):** откройте страницу, нажмите «Поделиться» → «На экран Домой» → «Добавить».
- После установки интерфейс подстраивается под экран, а статическая оболочка может открываться при временном отсутствии сети. Для входа и работы с Supabase всё равно нужен интернет.

Service worker кэширует только статические файлы этой панели и не кэширует ответы Supabase, сессии или личные данные.
